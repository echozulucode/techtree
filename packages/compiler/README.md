# @echozedlabs/techtree-compiler

Compile YAML trees to deterministic IR: parse → validate → lint → layout → emit.

```bash
techtree build examples/engineering-platform --profile capability
```

## Install

```bash
pnpm add -D @echozedlabs/techtree-compiler   # provides the `techtree` CLI
```

All `@echozedlabs/techtree-*` packages are released together with one version
(a fixed group through 0.x): use the same version of each.

Documentation, examples and the changelog live in the repository:
https://github.com/echozulucode/techtree
