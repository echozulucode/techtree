# @echozedlabs/techtree-schema

Zod authoring schemas (skill, capability, theme, tree) and their JSON Schema export.

Client bundles: import the capability constants and `capabilityData()` from the zod-free entry `@echozedlabs/techtree-schema/capability-data`.

## Install

```bash
pnpm add @echozedlabs/techtree-schema
```

All `@echozedlabs/techtree-*` packages are released together with one version
(a fixed group through 0.x): use the same version of each.

Documentation, examples and the changelog live in the repository:
https://github.com/echozulucode/techtree
