# @echozedlabs/techtree-state

Per-node state, status models and status derivation (available / locked from the prerequisite graph), plus storage adapters.

Client bundles: `@echozedlabs/techtree-state/status-model` has the status models, `deriveStatusView`, `prerequisiteIndex` and `pickFrontierNodeId` without zod.

## Install

```bash
pnpm add @echozedlabs/techtree-state
```

All `@echozedlabs/techtree-*` packages are released together with one version
(a fixed group through 0.x): use the same version of each.

Documentation, examples and the changelog live in the repository:
https://github.com/echozulucode/techtree
