# @echozedlabs/techtree-ir

The IR is the contract every TechTree tool consumes: compiled graphs (nodes, typed edges, any-of prerequisite groups, bands, tracks/lanes, positions) as plain TypeScript types.

## Install

```bash
pnpm add @echozedlabs/techtree-ir
```

All `@echozedlabs/techtree-*` packages are released together with one version
(a fixed group through 0.x): use the same version of each.

Documentation, examples and the changelog live in the repository:
https://github.com/echozulucode/techtree
