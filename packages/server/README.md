# @echozedlabs/techtree-server

Optional thin governance server: role-gated state mutations, an append-only audit log and an approval workflow (Fastify, `node:sqlite`, Node ≥ 22.5).

## Install

```bash
pnpm add @echozedlabs/techtree-server   # provides the `techtree-server` CLI
```

All `@echozedlabs/techtree-*` packages are released together with one version
(a fixed group through 0.x): use the same version of each.

Documentation, examples and the changelog live in the repository:
https://github.com/echozulucode/techtree
